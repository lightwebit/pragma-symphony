# Screenshots

Every image is generated from the real app by `npm run screenshots`, against a throwaway home filled with invented projects and sessions (`pragma-parser/examples/seed_demo.rs`). The live phases are played by a scripted fake `claude`, so nothing is spent and nothing real is shown. Each view comes in a dark and a light version.

To regenerate: `npm run e2e:build` once, then `npm run screenshots` (needs `ffmpeg` on the PATH to shrink the images; the demo files go to `C:/demo`, or to `PRAGMA_SHOTS_DEMO_ROOT`).
